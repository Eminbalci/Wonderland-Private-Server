# Monster Loot Drop System & Balancing

## 1. Natural Drop Mechanics & RNG Rules
- **No Guaranteed Drops:** Removed forced fallback drop item injection. If RNG rolls fail across all entries for a monster, **0 items are dropped** (mimicking authentic WLO drop rates).
- **Realistic Drop Chances:**
  - Common materials/fruits: 25% – 35%
  - Secondary materials: 15% – 20%
  - Rare items/potions: 5% – 10%
- **Drop Cap per Monster:** A single monster drop roll yields at most 1 (or exceptionally 2) distinct items per defeat.
