# Quests Rewards Calibration (Default 0 Gold / 0 Exp for Gathering & Exploration)

## Overview
- **Default Fallback**: Generic gathering points, scene triggers, collection markers, and unconfigured quests default to **0 Gold / 0 Exp**.
- **Verified Quests**: Authentic questlines (Robinson, Monkey, Minigames, Astrologer, Brelliat) award their official designated Exp and Gold values.
- **Admin Customization**: Server administrators can customize rewards individually via the Quest DB Manager GUI.
